- 品牌：土知 / 看懂土地，种好地。视觉米白 + 森林绿。
- 登录：手机号 UI 映射为 Better Auth 邮箱 `${phone}@phone.tuzhi.local`，演示验证码 `123456`（短信网关未接，前端已就绪）。微信按钮可点，提示「微信登录正在接入，请先用手机号」（开放平台未接）。Google / X / 邮箱折在「其他方式」。

- 知识库 50 篇独立明白纸；B 站优先真实 BV（酸化 BV1jT6TYXEjx），否则用 search.bilibili.com 关键词。不编造假 BV。
- 用量均为区间 + 按测土/按当地 + 宁少勿多。不写农药商品名处方。
- 社区为站内积分，不能提现。无「模拟现金」「悬赏 ¥」。
- 筛选项匹配数为 0 的芯片不渲染。植株封面与所选作物不一致时改用土面图。缺氮/酸化等通用文封面用土面，避免筛水稻露出玉米/麦苗。
- 诊断分流：新叶黄叶脉绿不直接判缺氮；喷药后 1–3 天突发优先药害；点片死棵优先土传病害。
